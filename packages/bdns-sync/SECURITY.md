# Security policy

*Puedes escribirnos en español.*

## Supported versions

Security fixes are released for the latest version published on PyPI. Earlier versions are not maintained.

## Reporting a vulnerability

**Please do not open a public issue.** Use [GitHub's private vulnerability reporting](https://github.com/cruzlorite/bdns-sync/security/advisories/new) (the *Security* tab, then *Report a vulnerability*), and include the version you use, how to reproduce the problem and its impact.

You will get an answer within 7 days. If the report is confirmed, a fixed release and a security advisory are published, crediting the reporter if they wish.

## Scope

In scope: any flaw in bdns-sync that compromises the confidentiality, integrity or availability of its users' systems or data, for instance credentials or personal data ending up in logs or tracebacks, or code execution triggered by a crafted response.

Out of scope: the content of the data the BDNS publishes (contact the [Intervención General de la Administración del Estado](https://www.infosubvenciones.es)) and the availability of the API itself.
